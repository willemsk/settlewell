# Case Studies

This section provides practical examples and real-world applications of the Settlewell calculation engine for estimating ground settlement during dewatering operations.

## Available Case Studies

- [Kauwereelstraat 31 Oud-Heverlee](kauwereelstraat.md): A real-world dewatering calculation for a single-family home with a basement. It demonstrates how to apply Settlewell to a specific soil profile and adjacent masonry structures.
- [Complex Analysis Example](example_analysis.md): A generic, complex testing scenario (`test_scenario_complex`) that illustrates the superposition of 4 dewatering wells, complex soil strata, multiple building loads, and the usage of Settlewell's multi-format export capabilities.
