# Project Orchestrator API Reference

The `settlewell.project` module defines the top-level `Project` orchestrator class and its associated frozen result containers (`HydraulicsResults`, `StressResults`, `SettlementResults`, `DamageResults`, `ProjectResults`).

## Overview

The `Project` class unifies all domain models, hydraulic and settlement physics solvers, building damage evaluation, visualization, and JSON serialization under a single object-oriented API.
